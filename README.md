> 무너지는 소비 습관을 막기 위해 탄생한  
> **개인 맞춤형 가계부 및 지출 목표 관리 플랫폼**입니다.  
> 단순 기록을 넘어, 목표 달성 여부와 통계 데이터를 통해  
> 사용자가 자신의 재정 흐름을 직관적으로 이해할 수 있도록 지원합니다.

## 📌 프로젝트 개요

본 프로젝트는 개인 및 소규모 조직이 수입과 지출을 체계적으로 관리할 수 있도록 지원하는 **가계부 기반의 자산 관리 시스템**이다.  
단순한 금액 기록을 넘어, 기간별·항목별 통계 분석을 제공하여 사용자가 자신의 소비 패턴과 재정 흐름을 한눈에 파악할 수 있도록 하는 것을 목표로 한다.

사용자는 수입 및 지출 내역을 항목별로 등록·조회·수정·삭제할 수 있으며,  
일/월/연 단위의 집계 및 추이 그래프를 통해 재정 상태를 직관적으로 확인할 수 있다.  
또한 카테고리 관리 기능을 통해 사용 목적에 맞는 유연한 지출 분류가 가능하다.

본 프로젝트는 **백엔드 API와 프론트엔드 UI를 분리한 구조**로 설계되었으며,  
RESTful API 기반의 데이터 처리와 통계 기능을 중심으로 실제 서비스 환경을 고려한 구현을 지향한다.  
이를 통해 CRUD 기능, 통계 데이터 처리, 인증 기반 접근 제어 등 실무에서 요구되는 핵심 기능을 종합적으로 경험하는 것을 목적으로 한다.

## 👤 사용자 관리

- 회원 가입 및 로그인 기능 제공
- 인증된 사용자만 가계부 기능 접근 가능
- 사용자별 수입·지출 데이터 분리 관리


### 💰 수입 관리

- 수입 내역 등록 / 조회 / 수정 / 삭제 (CRUD)
- 기간별 수입 내역 조회 기능
- 총 수입 금액 자동 집계


### 💸 지출 관리

- 지출 내역 등록 / 조회 / 수정 / 삭제 (CRUD)
- 결제 수단별 지출 관리
- 기간별 지출 내역 조회 기능
- 총 지출 금액 자동 집계


### 🎯 목표 설정 및 달성 관리

- 기간별 지출 및 저축 목표 금액 설정
- 실제 가계부 데이터 연동을 통해 목표 대비 현재 지출 및 저축 금액 자동 계산
- 목표 달성 여부(진행 중인 목표 / 종료된 목표) 시각적 표시
- 목표 초과 여부 직관적으로 제공


### 📊 통계 및 분석

- 일 / 월 / 연 단위 수입·지출 통계 제공
- 기간별 수입·지출 추이 그래프 제공
- 목표 대비 실제 지출 비교 통계 제공
- 재정 흐름을 한눈에 파악할 수 있는 요약 정보 제공


### 🔐 보안 및 접근 제어

- 인증 기반 API 접근 제어
- 사용자별 데이터 접근 제한
- 민감 정보 보호를 위한 보안 처리

## 🚩 젠킨스 파이프라인 파일 스크립트 코드

<details>
<summary><strong>🖥 Frontend (Vue)</strong></summary>
  
```
pipeline {
    agent any

    environment {
        // GitHub 저장소 URL
        SOURCE_GITHUB_URL = 'https://github.com/beyond-team3/project4-devOps-frontend.git'
        MANIFESTS_GITHUB_URL = 'https://github.com/beyond-team3/project4-devOps-manifests.git'

        // Git 설정
        GIT_USERNAME = 'guntinue'
        GIT_EMAIL = 'rjssn93@gmail.com'
    }

    stages {
        stage('Source Build') {
            steps {
                // 소스 코드 체크아웃
                git branch: 'main',
                    credentialsId: 'guntinue-git-auth',
                    url: "${env.SOURCE_GITHUB_URL}"

                // Node.js 빌드
                dir('frontend/armageddon') {
                    sh 'npm install'
                    sh 'npm run build'
                }
            }
        }

        stage('Docker Build and Push') {
            steps {
                script {
                    withCredentials([usernamePassword(credentialsId: 'docker-hub-guntinue', usernameVariable: 'DOCKER_USER', passwordVariable: 'DOCKER_PASS')]) {

                        // 파일 구조 로그로 확인
                        sh 'echo "===  현재 파일 구조 확인 ==="'
                        sh 'find . -maxdepth 3 -not -path "*/node_modules/*"'

                        dir('frontend/armageddon') {
                            // Dockerfile 존재여부 로그로 확인
                            sh 'echo "=== 📍 현재 위치 파일 확인 ==="'
                            sh 'ls -al'

                            if (isUnix()) {
                                sh "docker build --no-cache -t ${DOCKER_USER}/armageddon-frontend:${currentBuild.number} ."
                                sh "docker build --no-cache -t ${DOCKER_USER}/armageddon-frontend:latest ."
                                sh "docker login -u ${DOCKER_USER} -p ${DOCKER_PASS}"
                                sh "docker push ${DOCKER_USER}/armageddon-frontend:${currentBuild.number}"
                                sh "docker push ${DOCKER_USER}/armageddon-frontend:latest"
                                sh "docker logout"
                            } else {
                                bat "docker build --no-cache -t ${DOCKER_USER}/armageddon-frontend:${currentBuild.number} ."
                                bat "docker build --no-cache -t ${DOCKER_USER}/armageddon-frontend:latest ."
                                bat "docker login -u %DOCKER_USER% -p %DOCKER_PASS%"
                                bat "docker push ${DOCKER_USER}/armageddon-frontend:${currentBuild.number}"
                                bat "docker push ${DOCKER_USER}/armageddon-frontend:latest"
                                bat "docker logout"
                            }
                        }
                    }
                }
            }
        }

        stage('k8s Manifest Update') {
            steps {
                script {
                    withCredentials([
                        usernamePassword(credentialsId: 'DOCKERHUB_PASSWORD', usernameVariable: 'DOCKER_USER', passwordVariable: 'DOCKER_PASS'),
                        usernamePassword(credentialsId: 'guntinue-git-auth', usernameVariable: 'GIT_USER', passwordVariable: 'GIT_TOKEN')
                    ]) {
                        dir('frontend') {
                            // Manifest 저장소 가져오기
                            checkout([
                                $class: 'GitSCM',
                                branches: [[name: 'main']],
                                userRemoteConfigs: [[
                                    url: "https://github.com/beyond-team3/project4-devOps-manifests.git",
                                    credentialsId: 'guntinue-git-auth'
                                ]],
                                extensions: [[$class: 'CleanBeforeCheckout']],
                                poll: false
                            ])

                            sh 'echo "=== 📂 파일 목록 확인 ==="'
                            sh 'ls -al'

                            // Git 사용자 설정
                            sh "git config user.name 'guntinue'"
                            sh "git config user.email 'rjssn93@gmail.com'"

                            sh """
                                # 강제로 로컬 main 브랜치를 원격 main과 맞춤 (안하면 Detached HEAD 발생..!)
                                git checkout -B main origin/main

                                # 이미지 태그 수정
                                sed -i '' 's|image: .*|image: ${DOCKER_USER}/armageddon-frontend:${currentBuild.number}|g' frontend/deployment.yml

                                # 커밋
                                git add frontend/deployment.yml
                                git commit -m 'Update frontend image to ${currentBuild.number} [skip ci]' || echo 'No changes to commit'

                                # 최신 내용 당겨오기 (충돌 방지)
                                git pull origin main --rebase

                                # 푸시
                                git push https://${GIT_USER}:${GIT_TOKEN}@github.com/beyond-team3/project4-devOps-manifests.git main
                            """
                        }
                    }
                }
            }
        }
    }

    post {
        always {
            script {
                if (isUnix()) {
                    sh 'docker logout || true'
                } else {
                    bat 'docker logout || true'
                }
            }
        }
        success {
            withCredentials([string(credentialsId: 'armageddon-discord', variable: 'DISCORD')]) {
                discordSend(
                    description: """
                    **빌드 성공!** :tada:

                    **제목**: ${currentBuild.displayName}
                    **결과**: :white_check_mark: ${currentBuild.currentResult}
                    **실행 시간**: ${currentBuild.duration / 1000}s
                    **링크**: [빌드 결과 보기](${env.BUILD_URL})
                    """,
                    title: "${env.JOB_NAME} 빌드 성공!",
                    webhookURL: "$DISCORD"
                )
            }
        }
        failure {
            withCredentials([string(credentialsId: 'armageddon-discord', variable: 'DISCORD')]) {
                discordSend(
                    description: """
                    **빌드 실패!** :x:

                    **제목**: ${currentBuild.displayName}
                    **결과**: :x: ${currentBuild.currentResult}
                    **실행 시간**: ${currentBuild.duration / 1000}s
                    **링크**: [빌드 결과 보기](${env.BUILD_URL})
                    """,
                    title: "${env.JOB_NAME} 빌드 실패!",
                    webhookURL: "$DISCORD"
                )
            }
        }
    }
}
```  
